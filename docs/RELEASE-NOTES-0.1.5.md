# SRBMiner Monitor 0.1.5

- 事件紀錄及匯出僅保留分享成功 Accepted、失敗 Rejected／failed 與逾時 Timeout，不再填入算力表、Job received、分隔線、連線與啟停訊息。
- 總算力、每卡算力及趨勢在電腦時鐘切換分鐘時更新；第一筆與新礦工階段立即顯示。Accepted 收到訊息就更新，另每秒核對 API。
- 刪除原表單啟動方式、演算法／裝置偵測及示範模式。設定只保留現有 BAT 與貼上 BAT 內容兩種 BAT 來源。
- 貼上 BAT 時選擇礦工資料夾即可啟動，自動補 API 參數，保留其他挖礦參數與相對路徑。使用唯一名稱暫存檔，停止後刪除；設定內容以 Windows DPAPI 加密。
- 最近成功分享移至總算力上方，刪除綠底成功分享統計條；顯卡下方的 Accepted／Rejected 等統計繼續保留。
- 手動與自動重啟僅操作礦工；手動重啟不再被提示為自動重啟。

升級請停止舊版，完整解壓新版後執行 SRBMiner Monitor.exe。舊版指定 BAT 路徑與排程設定可沿用；不會自動挖礦。

整合驗證使用不挖礦的測試程序，包含背景 BAT、貼上 BAT、自動 API、DPAPI 還原、即時分享、事件篩選、分鐘算力及排程重啟；實際礦池接受結果仍需實機試跑。

Accepted 的 API 與輸出各自保留累積值，兩者先後送達都不會重複計數；包含所有 0.1.4 的 BAT 簡化、事件篩選與每分鐘算力變更。
