# SRBMiner Monitor 0.3.0

- 新增內建轉接器註冊、礦工能力描述、獨立監控階段及共用監控服務。
- 將 SRBMiner 的 API、分享輸出、BAT 辨識及 API 參數處理集中到專用模組。正式支援清單仍只有 SRBMiner-Multi。
- 設定頁增加挖礦程式選擇，礦工名稱、裝置與速率單位改由統一資料提供。
- 裝置資料預留 CPU/GPU、UUID/PCI 識別，演算法集合保留不同速率單位；不加總不同演算法。SRBMiner 目前仍限單演算法。
- 舊設定保留原路徑並自動遷移；首次寫入前備份舊格式。未知礦工、較新格式、損毀或不能解密的設定保留原檔，禁止覆寫。
- 保留 BAT、貼上啟動、程序樹控制、即時分享、硬體採樣、趨勢、事件與重啟流程。

新增轉接器的開發與驗收流程見 ADDING-MINERS.md。測試專用第二轉接器只存在測試專案，不包含在可攜式程式中。

升級請先結束舊版，完整解壓新版；監控程式開啟後不自行開始挖礦。程式組件名稱與本機資料目錄沿用舊版。
