# SRBMiner Monitor 0.1.6

- 「最近成功分享」直接根據 API 每秒確認新增成功分享，不必等待緩衝的礦工文字輸出。API 確認時清楚標示來源；對應文字到達後補上原始細節，同一筆不重複列出，也不捏造 GPU、延遲或礦工回報時間。
- 算力、功耗、效率、溫度、風扇、核心／顯存時脈及趨勢統一使用同一份硬體快照，不再混用每秒或每 5 秒的數據。
- 挖礦設定新增「硬體資訊更新間隔」：正整數及秒／分／時／天單位，預設 1 分鐘；舊版設定自動使用預設值。
- 儲存間隔即可套用，無須重啟礦工。首筆、新礦工階段與修改間隔後先顯示一筆，此後依電腦時鐘的設定區間整點更新；預設為每分鐘 :00。
- 最近成功分享、Accepted、Rejected、Timeout 與事件紀錄保持即時，不受硬體間隔影響。
- API 先到、文字先到、延遲文字補全、外部礦工歷史基準及新程序階段都包含去重測試。

停止舊版後完整解壓新版，沿用 BAT 即可。欲調整間隔，在挖礦設定輸入數值、選擇單位，按「儲存設定」。Windows 整合驗證使用不挖礦、不連礦池的測試程序。
