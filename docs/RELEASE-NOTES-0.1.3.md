# SRBMiner Monitor 0.1.3

- 修正選取單一 GPU 後 Accepted 顯示 —：單卡可使用 API 總計。
- 擷取綠色 share accepted 訊息，補足每卡成功／拒絕統計；統計表使用累積值覆蓋，避免重複計數。API 與輸出不相加。
- 總覽新增全部 GPU Accepted 數、最近成功分享及礦工即時輸出。每次啟動重設輸出統計階段。
- 指定 BAT 使用隱藏主控台與標準輸出／錯誤重新導向，無須另外查看 CMD。NUL 標準輸入避免尾端 pause 等待隱藏鍵盤輸入。
- 礦池卡只顯示位址與設定來源，從 BAT 的 SRBMiner --pool 取得設定，移除 Worker／連線／回應延遲等欄位。
- 重啟與排程僅重啟礦工，應用程式持續運行；排程到期、等待與重新啟動都有事件及狀態顯示。

## 使用方式

1. 先停止舊版與舊礦工，將本版本完整解壓縮到新資料夾。
2. 執行 SRBMiner Monitor.exe，選擇先前已建立的監控 BAT（含 --api-enable）。
3. 儲存並啟動，總覽查看 Accepted 與下方礦工即時輸出。
4. 自動重啟礦工需先啟動礦工，再勾選啟用並套用。運行倒數結束後先停止礦工，等待指定分鐘後重新啟動；監控視窗不關閉。

資料來源未知仍顯示 —；礦池位址來自設定時會標示來源，不將其當成網路連線確認。既有 BAT 的相對路徑與 %~dp0 保持原本意義。此版本的整合驗證使用不挖礦的測試程序，實際 RTX 5080／礦池接受結果仍需使用者試跑。
