# SRBMiner Monitor 0.1.8

- 挖礦設定新增「礦工非預期退出後自動重啟」，預設關閉，儲存後立即生效；不必啟用定時排程。意外退出後等待 10 秒再啟動。
- 修正定時排程遇到意外退出便永久暫停的行為：確認退出後，依「停止後等待時間」開始完整倒數，時間到重啟礦工。循環模式重新計算運行時間，單次模式在成功重啟後完成。
- 兩項同時啟用以定時排程的等待時間為準，共用程序鎖，避免雙開。自動啟動失敗會依同一等待時間重新倒數，不會卡在啟動中。
- 手動停止取消任何待重啟動作；關閉獨立異常重啟選項並儲存，可取消其 10 秒倒數。重新開啟 GUI 不會自行開始挖礦。
- 所有重啟只操作目前受管理的礦工，監控視窗保持開啟；自動重啟沿用目前運行的 BAT，尚未啟用的 BAT 修改不會被自動套用。

驗證包含核心可控時鐘測試，以及 Windows 無主控台 GUI 內實際結束不挖礦測試程序：獨立復原、手動停止取消、定時排程遇到意外退出後完整等待、GUI PID 不變。另保留正常定時停止／等待／重啟驗證。測試不連外部礦池、不挖礦。

請先結束舊版，再完整解壓新版 ZIP。原有 BAT 與設定可沿用；新選項需自行勾選並儲存。
