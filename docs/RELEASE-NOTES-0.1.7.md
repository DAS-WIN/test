# SRBMiner Monitor 0.1.7

- 停止訊號改由短暫的獨立輔助程序送給受管理礦工；監控 GUI 不再 AttachConsole 到礦工主控台，避免受到主控台停止／關閉訊號影響。
- 「停止礦工」、手動「重啟礦工」與自動排程共用修正後的流程，只操作 BAT／礦工程序樹。監控視窗保持開啟。
- 總覽明確標示「停止礦工」，離開按鈕改為「結束應用程式」，避免混淆兩種操作。
- 「最近成功分享」及事件只顯示 CMD 的原始分享訊息，移除 API 確認文字與代填事件。數字 Accepted／Rejected 仍獨立從 API 核對。
- 保留硬體更新間隔的秒／分／時／天設定，預設 1 分鐘。

Windows 驗證改用沒有附掛主控台的 WinExe GUI 主機，實際操作停止／重啟按鈕，檢查礦工停止或更換 PID、GUI PID 不變、視窗持續可見且未接入主控台。另執行一分鐘運行、一分鐘等待的自動重啟測試。測試程序不挖礦。

升級請先停止舊版，將新版完整解壓縮至新資料夾；原有 BAT 與監控設定可沿用。
