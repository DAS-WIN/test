# SRBMiner Monitor 0.2.0

- 整理核心程式結構，分開程序介面、生命週期控制、排程及顯示格式。
- 測試資料統一使用合成數據、一般化裝置名稱、保留網域與錢包占位值。
- 移除對話引用、開發過程文字及過時的版本草稿，重整使用、架構、資料來源及驗證文件。
- 介面版本號改由程式組件取得，與封裝版本保持一致。
- 發布流程增加內容檢查，封裝排除本機設定、運行日誌、暫存 BAT 與測試執行檔。

保留現有 BAT 啟動、即時分享、硬體更新間隔、定時重啟及非預期退出自動重啟功能。

升級前請先結束程式，再完整解壓新版至新資料夾。既有本機設定可沿用；重新開啟程式不會自行開始挖礦。
