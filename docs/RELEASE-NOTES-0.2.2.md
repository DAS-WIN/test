# SRBMiner Monitor 0.2.2

延續 0.2.1 的 0.1.8 分支，不以 0.2.0 改寫。

- 改為逐筆成功 share 紀錄，保存原始文字、礦工時間與接收時間、最新 API 算力及採樣時間、該 share 前最後回報的礦池工作難度與時間。不再紀錄平均值，也不以 API 增量製造 share 紀錄。
- 挖礦設定可自訂紀錄資料夾，儲存即套用；留空使用預設 MiningLogs。舊資料保留原處。寫入失敗會顯示提示。
- 保留最近 10／30／60 分鐘 Accepted 平均，新增本次挖礦的整體平均。四者與硬體資訊同步更新；Accepted 數字與原文仍即時更新。
- 礦工停止後暫停 API／GPU 資料查詢與平均值更新，重新啟動後恢復；定時重啟及異常恢復倒數仍正常工作。
- 總覽新增非預期關閉次數，本次監控應用程式運行期間累計，排除手動停止、重啟與定時停止。

log 為 UTF-8 JSON Lines。未知算力、礦工時間、難度保存為 null；算力為該 share 到達時最近 15 秒內的 API 樣本，並非重新測量的瞬時算力。平均值以本次礦工運行為範圍，重啟重新起算。

請停止並結束舊版，再完整解壓 Windows x64 套件，執行 SRBMiner Monitor.exe。保留原有 BAT 設定；不包含 SRBMiner 本體。驗證使用不挖礦的 Windows 測試程序，未執行真實 GPU 挖礦。
