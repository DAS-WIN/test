# Windows 驗收步驟

目標：Windows 10/11 x64、SRBMiner 3.8.0、NVIDIA 驅動。

## UI 與示範

- 啟動 `Start-Demo.cmd`，應標示「示範模式 · 模擬資料」，每 5 秒新增樣本。
- 驗證 1440×900、1100×720、125%／150% DPI；頁面及 GPU 表格可捲動。
- 切換趨勢指標、時間範圍、GPU／全部 GPU，巡覽三頁，篩選與匯出事件。
- 關閉視窗縮至系統匣、雙擊還原、「停止並退出」真正結束。

## 設定與真實資料

- 用官方執行檔讀取演算法，確認去重、保存、重開仍有清單；無效執行檔與超過 10 秒不應清空原清單。
- 與 `--list-devices` 核對 ID；不相容格式可手動填入。
- 填自己的礦池與錢包，測試 TCP／TLS；必要欄位未填妥時不可儲存並重啟。
- 啟動後只應有一個受管理程序，API／nvidia-smi bus 對應正確，感測值與官方工具一致。
- 運行時保存新 API port 草稿，舊礦工監控仍使用舊 port；重啟後才改用新值。
- 多輪更新 Accepted／Rejected 不重複累加；沒有來源的欄位保持 —。
- 中斷 API，保留舊讀值與時間，15 秒後顯示過期，圖表不補值；恢復後保留缺口。
- 外部礦工僅監控，不能接管啟停；port 被占用時不得啟動第二個礦工。
- 密碼不以明文儲存，重開可解密，事件與匯出不包含密碼。

## 排程

- 設運行 1 分鐘／等待 1 分鐘循環，確認等待從完全退出後開始。
- 等待時手動停止，超過 1 分鐘仍不可再啟動。
- 關閉排程不停止礦工；手動重啟重新計時；單次執行完保持礦工運行並關閉排程。
- 強制結束受管理礦工：定時排程依等待分鐘重啟；獨立異常重啟選項依 10 秒倒數重啟。手動停止取消待重啟；重開 GUI 不自行挖礦。
- 模擬啟動／停止失敗，不產生第二個程序，錯誤可見。

驗證後將去識別化 JSON 與文字輸出加入具版本註記的 fixtures，才可將對應項目標示為實機相容性通過。
