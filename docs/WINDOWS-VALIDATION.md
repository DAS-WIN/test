# Windows 驗收

使用獨立資料夾與測試設定執行，確認以下行為。

| 範圍 | 預期結果 |
| --- | --- |
| 首次啟動 | 深色視窗正常顯示；不自行開始挖礦；未知數據顯示「—」 |
| 現有 BAT | 保留原始檔；監控副本僅補 API；相對路徑正常 |
| 貼上 BAT | 使用指定工作目錄；內容加密保存；停止後清理暫存 BAT |
| 背景程序 | 不顯示 CMD；輸出出現在應用程式；僅管理自身啟動的程序樹 |
| 分享 | 成功、拒絕、分享逾時即時顯示；API 與輸出不重複計數 |
| 硬體 | 秒／分／時／天設定立即套用，全部欄位同步採樣 |
| 礦池 | 僅顯示可解析的位址與來源，未知時不推測 |
| 手動停止 | 礦工停止，GUI 保持開啟，待重啟動作取消 |
| 手動重啟 | 礦工更換 PID，GUI PID 不變 |
| 定時重啟 | 完全停止後才開始等待，時間到啟動；單次及循環模式正確 |
| 非預期退出 | 獨立選項使用十秒等待；定時排程使用設定等待分鐘；不雙開 |
| 啟動失敗 | 自動流程重新倒數再試；停止失敗禁止啟動第二個礦工 |
| API 中斷 | 保留最後硬體資料，標示連線狀態，不補造歷史 |
| 關閉與退出 | 關閉視窗縮至系統匣；明確退出才停止礦工並結束 |
| 重新啟動 GUI | 載入設定，不自行啟動礦工或啟用排程 |

診斷紀錄僅在本機保存。發布套件與問題回報附件應排除私人 BAT、錢包資料、設定檔及個人運行日誌。
