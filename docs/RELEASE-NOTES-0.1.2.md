# SRBMiner Monitor 0.1.2

修正深色介面、演算法選單與偵測操作回饋，加入指定 BAT 的實際啟動及 API 監控。

- 主視窗明確套用深色背景與基本樣式，區塊標題繼承淺色字，捲動軸改為深色。
- 演算法改為不可編輯的下拉選單；表單啟動時驗證選項來自所選礦工的已讀取清單。
- 讀取演算法／偵測顯卡提供執行中、完成、無輸出、失敗、逾時，以及退出碼、耗時、stdout／stderr 與複製結果。唯讀偵測在示範模式仍可操作。
- 頂部可直接切換至實際監控，另附 Start-Real.cmd。API 狀態與操作結果分開顯示，連線輪詢不會蓋掉偵測回饋。
- 挖礦設定新增「指定 BAT」：選擇既有 .bat／.cmd，使用該檔案的挖礦參數與所在資料夾，不必重填錢包或 GPU。
- 「建立監控副本」保留原 BAT 與其他參數，只補 API 旗標與連接埠。支援單一 SRBMiner 命令與常見 if 檔案檢查、pause、setlocal、%~dp0 及續行。無法安全判讀的複合指令會明確提示，不修改原檔。
- Windows Job 追蹤 BAT 與其子程序；start 啟動後父 cmd 先退出仍能停止、重啟；不接管外部礦工。

## 使用既有 BAT

1. 結束舊版 GUI，將套件完整解壓縮至新資料夾，執行 Start-Real.cmd 或 SRBMiner Monitor.exe。
2. 進入挖礦設定，勾選「指定 BAT」，選擇已建立的挖礦 BAT。
3. 若提示沒有 API，點「建立監控副本」，將 .monitor.bat 存在原 BAT 的同一資料夾。
4. 確認 API port（預設 21550）一致，點「儲存並啟動 BAT」。
5. BAT 主控台會開啟；總覽顯示 API 連線狀態與實際讀值。未提供欄位維持 —。

批次檔本身設定的 TLS、礦池、Worker、停卡溫度與其他挖礦選項保留。控制台的 pause 不會被當作礦工已停止；停止操作先嘗試正常退出，10 秒後才終止受管理程序樹。

本版的 Windows 整合測試使用不執行任何雜湊運算的 API fixture，驗證 BAT -> 程序管理 -> 本機 HTTP -> 總覽、停止與重啟；這不等於已在使用者 RTX 5080 上完成真實挖礦驗收。
